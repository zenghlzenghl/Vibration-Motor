## 🚀 5分钟快速上手

### 1️⃣ 硬件连接

```
CA51M550 开发板
├── P0.0 ──→ 按钮 (另一端接GND)
├── P0.1 ──→ 充电IC状态引脚
├── P0.2 ──→ LED (串联220Ω电阻)
├── P0.3 ──→ MOSFET Gate (驱动马达)
├── P0.5 ──→ 充电器分压检测
├── VCC  ──→ 电池正极 (3.7V Li-ion)
└── GND  ──→ 公共地
```

### 2️⃣ 编译步骤

```bash
# 使用Keil uVision
1. 打开 Keil → New Project → 选择CA51M550
2. 添加所有 .c 文件到工程
3. 设置Include路径: ..\project
4. 按 F7 编译
5. 连接下载器 → F8 烧录
6. 按复位键运行！
```

### 3️⃣ 操作说明

```
操作          功能
─────────────────────────────
长按(>1.5s)   开机 / 关机
短按(<1.5s)   切换振动模式(10种循环)
插入充电器    自动唤醒+显示充电状态
拔出充电器    自动关机进入省电模式
无操作5分钟   自动关机省电
```

## ⚡ 10种振动模式

| ID | 模式名称 | 时序特点 | 应用场景 |
|----|---------|----------|----------|
| 0 | **IDLE** | 不振动 | 待机省电 |
| 1 | **CONTINUOUS** | 持续振动 | 测试/持续提醒 |
| 2 | **INTERVAL_1S** | 500ms振+500ms停 | 节奏提醒 |
| 3 | **INTERVAL_2S** | 500ms振+1500ms停 | 低频间歇 |
| 4 | **PATTERN_1** | 短-短-长停 | 消息通知 |
| 5 | **PATTERN_2** | 三连击+长停 | 紧急警报 |
| 6 | **PATTERN_3** | 长短组合 | 来电/闹钟 |
| 7 | **RAMP_UP** | 渐强振动 | 唤醒效果 |
| 8 | **RAMP_DOWN** | 渐弱振动 | 平缓停止 |
| 9 | **RANDOM** | 随机振动 | 游戏反馈 |

**时序图示例**：

```
马达:  ON  OFF ON  OFF ON  OFF ...
       ──┘   └──┘    └────┘
       200m 100m 200m  500m
```

## 🔧 如何配置

### 方法1：修改 config.h（推荐）

打开 `config.h`，找到需要修改的参数：

```c
/* 示例：调整为快速响应版本 */
#define BUTTON_LONG_PRESS_MS  1000     /* 1秒即判定长按 */
#define AUTO_POWEROFF_TIME_MS 120000   /* 2分钟自动关机 */
#define LED_BLINK_500MS_DURATION 200   /* 更快的闪烁反馈 */
```

**配置分类**：
- ⏱️ 时钟频率 (`F_CPU`)
- 🔌 引脚分配 (`BUTTON_PIN`, `LED_PIN`, ...)
- ⏰ 时间参数 (消抖、闪烁、振动时序)
- 🔋 电源管理 (自动关机时间)
- 🔌 中断向量 (通常不需要改)

### 方法2：使用默认配置

直接编译运行，默认配置已针对通用场景优化！
